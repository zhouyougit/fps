# core · 核心舱 — 轮次记录

## 基线（Round 0）
- 尺寸/边界：x -19..19，z -13..13（38 x 26）。
- 碰撞盒 108；cover 25；walkable 3040 / 可达 3040。
- medium 960x540 实测：reactor 325 calls / 298k tris；west 283 / 168k；east 244 / 228k。
- 截图：`tools/mapwork/shots/core/base_*.png`。
- 现状：中心反应堆体块 + 四角罐体 + 两侧马道，墙面大面积平整；缺少控制室、
  管线层次与设备细节；空间比港区小很多。

## 10 轮路线（可调整，但每轮必须记录）
1. 勘察：列出空旷墙面、重复体块、缺失设施。
2. 扩大外环：新增东西两侧服务走廊/设备间，bounds 外扩。
3. 二层环廊：完整环形马道、楼梯、栏杆、观察窗。
4. 反应堆细节：管道、阀门、泵组、仪表、警示环、电缆桥架。
5. 控制室：控制台、全息屏、座椅、机柜、UPS、空调。
6. 机房设备：变压器、配电柜、备用发电机、冷却泵、储罐。
7. 地面/墙面：格栅、排水沟、警示漆、锈迹、油污、标牌。
8. 光照：红色应急、冷白工作灯、蓝色状态灯、反应堆脉冲。
9. 掩体与动线：柱、控制台、设备箱，保证通道顺畅。
10. 收尾：性能、碰撞、可达性、整体一致性。
